使用说明

如何获取 Cookie（同步「我的角色 / 推荐方案」需要）：
① 用浏览器打开 mihoyo.com（米游社官网）并登录你的账号；
② 按 F12 打开开发者工具 → 切到「网络（Network）」标签 → 刷新页面，点任意一个请求， 在「请求头（Headers）」里找到 cookie 字段，整段复制（很长，全部复制）；
③ 打开 header 的「同步数据」弹窗，把 Cookie 粘贴到输入框 → 点「保存 cookie」→ 勾选 「更新我的角色 / 更新推荐方案」→ 点「更新」。
（也可用弹窗里的「米游社 Cookie 书签」一键复制，只需拖一次；Cookie 缓存在本地 data/.cookie.json，不回显，需更换时直接覆盖粘贴。）

同步数据：「同步数据」弹窗可勾选四项——更新数据库（角色/音擎/驱动盘/邦布基础数据，无需登录）、 更新我的角色（你的账号真实角色，需 Cookie）、更新推荐方案（米游社养成指南，需 Cookie）、 更新工坊数据（全服玩家配装，全量爬取耗时数小时，慎勾）。可多选，一次更新。数据有缺失时 对应页面会红字提示需要同步哪一项。

我的角色（01）：账号角色一览汇总表（每行一个角色，行列可拖拽排序，无卡片视图）。 角色列旁两个按钮：「养成」在行内就地展开练度面板；「配置」打开「养成配置」弹窗 （推荐音擎 / 4/5/6 号位主词条 / 有效副词条勾选，也可从推荐方案一键「应用」）。属性列各含 「目标 N」子行与圆形达成率，另有 缺口 与 穿透值/贯穿力/属性伤害（标元素）列。

练度面板（「养成」手风琴，从上到下）：
· 角色详情条带：技能养成（技能图标 + 当前 Lv / 玩家样本该技能众数目标 + 下方等级分布图， 达标金色）+ 影画 / 潜能觉醒；
· 配装对标：音擎与套装组合的 我的 / 养成指南推荐 / 工坊真实玩家 三方对照；
· 驱动盘提升：六件盘简卡，各盘「命中 N」与重刷概率四口径（重刷提升概率 / 持平概率 / 保词条提升概率 / 初始4/3词条提升概率），最值得重刷的盘金框盖章「先刷」；标题可一键跳转「模拟 → 驱动盘提升模拟」精算；
· 面板分布：每属性一行，X 轴 = 玩家分位（0-100%，上下行横向可比）。青瓷密度 = 玩家真实分布， 浅金带 = 推荐区间（中档中位 ~ 高档上限），金色点 = 我的分位，紫色三角 = 已设目标分位；
· 配比散点：两幅 2D 玩家配比密度散点，下拉切换属性对，金色菱形 = 我的位置。

目标与缺口：目标数值在属性列「目标 N」子行点击修改（暴击率填 60 即 60%；留空保存 = 清除）。设了目标后，它的玩家分位不显示在表格，而是以面板分布图里的紫色三角呈现。「缺口」列 直接显示毕业状态——已毕业 ✓ / 缺口 N（附逐属性「差 N 条」明细，靠副词条无法补足的标 「不可补」）/ 未设目标。命中与缺口口径由「养成配置」勾选的有效副词条决定（攻击/生命/防御 只有百分比变体计入命中，固定值不参与）。

驱动盘（02）：清盘决策工具，纯知识、不接个人盘。上半「全套装清理速查」：30 套按判定倾向 分色徽章（泛用4件套 / 角色专属套 / 仅2件套可用 / 未来套 / 冷门），行含套装图标与 4件套适配角色、 2件套散件实况；点击某套装 → 下半显示该套的清理决策卡：适配职业、4件套适配角色（官方 wiki 推荐 × 工坊实况）、逐槽主词条三级判定（保留 / 视词条 / 分解）、有效副词条清单与主词条×副词条协同证据图。 判定倾向与逐项判定均可点击修正（覆盖持久化，金色圆点 = 已手工调整，可逐项/全部重置回自动）。

模拟（03）：两个 tab——驱动盘提升模拟（可调权重 / 定向道具后精算「新盘超过当前盘」的提升 概率，含持平 / 保词条 / 初始4/3词条口径）；成长极限模拟（副词条强化次数分配到 X/Y（或 X/Y/Z） 轴的帕累托有效前沿，2D/3D）。

资料（04）：角色 / 音擎 / 驱动盘 / 邦布 四库 + 总览 五个子面板。角色行技能图标可点击弹出 「技能数值」弹窗（该技能每级伤害倍率等）。「总览」基于工坊高练度玩家样本（排行榜上榜玩家， 比全服平均更强，不是全服分布），展示 装配评分分布 / 影画档位金字塔 / 角色拥有率——需先同步「工坊数据」。

副词条成长与命中：「有效副词条」勾选决定哪些属性算命中；驱动盘词条旁标注 ×n（该词条强化 次数，按成长规则由词条数值推算），命中次数 = 六个盘落在有效副词条上的词条次数之和（每个词条本身算 1， 每强化一次再 +1）。

最终面板数值：优先显示账号接口返回的真实值（和游戏内一致）；「计算明细」是用属性库基础值 + 装备推算的， 4 件套条件效果等未计入，可能与实际略有出入。

我的角色 · 数据导入

          

            静态版没有后端服务器，浏览器无法直连米游社接口（CORS
            拦截），且手机端无法运行采集脚本（书签/控制台仅电脑可用）。
            请在电脑上用采集书签抓取（会自动下载
            zzz-chars.json），把文件传到手机（微信文件助手等），再点下方「选择 JSON 文件」导入——
            数据只保存在本浏览器 localStorage，不会上传。
          

          

            ① 电脑上安装采集书签（只需一次）：把下面链接拖到书签栏（部分浏览器不支持拖拽，可右键链接 → 添加到书签栏）：

            采集我的角色

            （书签内容是注入本站 collect.js 的小脚本，很短）

            user.mihoyo.com（米游社网页版，需已登录），点书签「采集我的角色」→ 脚本自动抓取你的全部角色，复制到剪贴板并下载 zzz-chars.json（弹出确认框）。
